# OpenArm 下見（2026-11-12）

次のマイルストーンの候補として、OpenArm v2（両腕）を KeiArm と同じ作り方（物理は MuJoCo、それ以外は自作、ブラウザで閉ループ）で扱えるかを 1 セッションで確かめた。**結論: 扱える。決め手だった懸念 2 点（物理の重さ、配信サイズ）はどちらも解消した。** 実装はまだ何もしていない。

## 対象

- リポジトリ `enactic/openarm_mujoco` @ `1daab06`（2026-11-09）、Apache-2.0。`runs/spike/openarm_mujoco/` に clone（git 管理外）
  ```
  git clone https://github.com/enactic/openarm_mujoco.git runs/spike/openarm_mujoco
  git -C runs/spike/openarm_mujoco checkout 1daab06
  ```
- 使ったシーン: `v2/pedestal/move_puck_scene.xml`（台座に両腕、机、70×70×44 mm のパック、ゴール印 2 つ、`home` キーフレーム）
- Menagerie には入っていない。Enactic 自身が `@mujoco/mujoco` 3.17.0 と three.js でブラウザ版を公開している（`web/`。IK による手先姿勢の操作のみで、方策はない）
- 検証スクリプトは `tools/openarm_spike/`。リポジトリ直下から実行する

## モデルの中身（`v2/openarm_bimanual.xml`）

| 項目 | 値 |
|---|---|
| 関節 | 片腕 7 + 指 2（指 2 本は等式拘束で連動）、両腕で nq = 18 |
| アクチュエータ | 位置制御、片腕 8 個（7 関節 + 指 1）、計 16。kp 230/190/30（肩・肘・手首）、出力制限 ±40/27/7 N·m |
| 指 | 回転式の平行グリッパ。指先は手先サイトから 0.15–0.17 m 先。開き幅は最大約 139 mm（`finger_joint` = ∓0.785 で全開、0 で閉、制御範囲は 0.4 まで押し込める） |
| カメラ | 手首 `camera_wrist_left/right`（fovy 66°）。シーン側に `frontcam`、`tablecam` |
| 物理設定 | timestep 0.001、implicitfast、elliptic cone、impratio 10 |
| 手先サイト | `left/right_ee_control_point`（手首。指先ではない） |
| メッシュ | v2 全体 22 MB。`move_puck` が読むのは 79 ファイル 19.9 MB、42 万面（うち見た目用 33 万面、台座 1 個で 16 万面） |

## 結果

### 1. 物理の重さと timestep → 1/240 秒で問題なし

右腕でパックを真上から掴んで 15 cm 持ち上げるスクリプト（`tools/openarm_spike/grasp.py`。減衰最小二乗 IK、8 mm キャロット、30 Hz）:

| timestep | 重力補償 | 持ち上げ高さ | アームと机の接触 | 実時間比（物理 + IK） |
|---|---|---|---|---|
| 0.001（既定） | あり | 148 mm | 0 | 9.4× |
| 1/480 | あり | 148 mm | 0 | 13.1× |
| **1/240（KeiArm と同じ）** | **あり** | **148 mm** | **0** | **15.7×** |
| 0.001 | なし | 144 mm | 68 ステップ | 9.3× |
| 1/240 | なし | 144 mm | 86 ステップ | 15.4× |

- **timestep は KeiArm と同じ 1/240 × 8 サブステップで掴める。** 1 ms と結果が同じで、発散もない
- **重力補償が必須。** 補償なしでは各関節が目標から最大 0.023 rad たわみ、手先が 14 mm 沈んで机に当たる。MuJoCo の `gravcomp="1"`（ボディ）で解消する。Enactic のブラウザ版も同じ理由で `qfrc_applied = qfrc_bias` を入れている
- 物理だけ（接触なし、保持）の実時間比は Python で 75–89×（1/240）

### 2. カメラ 3 台込みの速度 → 十分

`tools/openarm_spike/render_speed.py`: 160×120 で `frontcam` と手首 2 台を毎制御ステップ描画しても **実時間比 5.3×**（Python、EGL、元のメッシュのまま）。SO-101 の 2 台より遅いが、データ収集には十分。

手首カメラは把持の接近中ずっとパックを捉える（`docs/openarm/wrist_approach.png`。上から高さ 15/10/4 cm）。ただし home 姿勢では視野の半分以上が自分の指で埋まる（カメラが指を見下ろす位置にある）。

### 3. ブラウザ（WASM）→ 読み込み・実行とも可

`tools/openarm_spike/wasm_hold.mjs`（Node、`web/node_modules/@mujoco/mujoco` 3.17.0）:

- 79 ファイル（19.9 MB）を `MjVFS` に入れて `from_xml_path` で読み込める。コンパイル 1.6 秒
- 保持 2 秒の実時間比: timestep 1 ms で 9×、**1/240 で 45×**（Python の約半分）
- **重力補償はコンパイル後に `body_gravcomp` を書き換えても効かない**（`ngravcomp` を合わせても `qfrc_gravcomp` は 0 のまま）。**XML の段階で `gravcomp="1"` を入れれば効く**（たわみ 0.0000 rad）。`tools/openarm_spike/wasm_gravcomp.mjs`。KeiArm では Python 側で組んだシーン XML を書き出すので、そこに入れれば済む

### 4. 配信サイズ → 見た目用メッシュを 25% に間引いて約 5.6 MB

`tools/openarm_spike/decimate.py`（trimesh + fast-simplification。**頂点を結合してから間引く**。STL は面ごとに頂点を持つので、結合しないと穴だらけになった）:

| 残す面の割合 | 見た目用の面数 | 見た目用ファイル | 見た目 |
|---|---|---|---|
| 100% | 33 万 | 17.6 MB | 元のまま |
| **25%** | **8.2 万** | **3.4 MB** | **元とほぼ区別できない** |
| 10% | 4.6 万 | 2.0 MB | 全体は保つが、手首カメラに大写しになる指の付け根が崩れる |
| 5% | 4.1 万 | 1.9 MB | 指まわりが大きく崩れる |

比較画像は `docs/openarm/decimation.png`（上から 100/25/10/5%。左: 全景、中: 右手の寄り、右: 右手首カメラ）。衝突用メッシュ 2.2 MB はそのまま使う。**25% なら合計約 5.6 MB で、SO-101 の 17 MB より小さい。** 手首カメラに写る指だけ細かく残し、台座は大きく削る、という分け方もできる。

### 5. 真上から掴める範囲 → 片腕 30×45 cm、両腕共通は中央の約 20×20 cm

`tools/openarm_spike/reach.py`（`docs/openarm/reach.png`）: 机上 2 cm の高さで、指を真下に向けた姿勢（ヨー 8 通り）に IK が収束する点。

- 片腕: x 0.08–0.41 m、自分の側の y 0.1–0.5 m 程度（2.5 cm 格子で 270 点）。SO-101 の出現範囲（半径 0.13–0.22 m、±60°）よりずっと広い
- **両腕とも届く範囲は x 0.18–0.38 m、y −0.10–0.10 m（53 点）**。持ち替え（右手で取って左手に渡す）はここで行う
- 机（奥行き 0.82 m）の奥半分には真上からは届かない。傾けた把持は未調査
- IK は home 姿勢から始めた局所解なので、実際の範囲はこれより少し広い可能性がある

## KeiArm の仕組みのうち流用できるもの・作り直すもの

- **そのまま使えそう**: シード管理と `MjSpec` でのシーン組み立て、評価ハーネス（段階・違反・符号検定・外乱）、DART と DAgger の収集、行動チャンク学習、ブラウザ側の three.js 描画・WASM 物理・ONNX 推論
- **作り直し**:
  - エキスパート。2 本の腕で役割分担し、互いにぶつからないようにする。7 関節なので手先の姿勢も指定できる
  - シーン生成。机・台座・物体を自作し、Enactic のシーンは参考にとどめる
  - 行動の次元（6 → 16）
  - カメラ構成（正面 1 台 + 手首 2 台）
